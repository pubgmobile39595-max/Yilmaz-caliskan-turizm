# Yılmaz Çalışkan | Premium Turizm Sitesi

Modern, sinematik ve lüks hissiyatlı turizm web sitesi.

## Özellikler
- Tam responsive tasarım
- Smooth scroll & animasyonlar
- Premium dark luxury tema
- Mobil menü
- Sayaç animasyonları
- Testimonial slider
- İletişim formu

## Nasıl Çalıştırılır?
1. Dosyaları bilgisayarına indir
2. `index.html` dosyasını tarayıcıda aç
3. Veya GitHub Pages'e yükle

## Teknolojiler
- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript

Geliştirici: Grok tarafından hazırlanmıştır.
